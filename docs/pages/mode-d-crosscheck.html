1. 被检验的是什么

外空间的能带补全:把希尔伯特空间切成 $1 = P + K + Q$——$P$ 为活性窗口(11 带 $d+p$), $K$ 为直到 $n_x$ 的显式外空间(带真实 DFT 能量与矩阵元),$Q$ 为 $n_x$ 之上直到平面波截断的 尾部(永不枚举)。用 Schur 补把 $Q$ 精确消去:

$$\Sigma_P(\omega)=T_{PP}+\bigl(W_{PK}+T_{PK}\bigr)\bigl[\omega-H_{KK}-T_{KK}\bigr]^{-1}\bigl(W_{KP}+T_{KP}\bigr), \qquad T_{XY}=W_{XQ}\,G_Q(\omega)\,W_{QY}$$

尾部因此出现在三处:直接路径 $T_{PP}$、显式带哈密顿量的修饰 $T_{KK}$、以及 $P\!\leftrightarrow\!K$ 耦合的修饰 $T_{PK}$。近似只有两个:$G_Q$ 取平面波对角的自由电子形式 $D_G=1/(\omega-\bar V-|k_f+G|^2)$,以及每条显式带只需一个矢量 $\chi_X=\hat Q\,\Delta V|\psi_X\rangle$(其中 $\hat Q$ 只减掉已有的 $n_x$ 条显式带投影)。

对照的 MODE C 是我们的精确 $\omega$ 分辨 Feshbach 折叠(生产路径用块 Lanczos 连分式实现; 本页在同一套 160 带数据上用直接求解给出同一个目标量)。

6. 结论与未决

结论:在 6×6 非 SOC 理想 V$_S$ 上,MODE D 用 100 条显式带 + 解析尾部复现了 MODE C (160 带精确折叠)的谱,DOS 层面的差异在 5 meV 分辨率以下;而同样丢掉 60 条带却不加尾部 (drop-block)会把深能级推 10 meV。

尚未证明:$\chi$ 的带投影性质使第 4 节是下界(需 Fortran $\chi$ 导出);弛豫几何、 12×12 稀释极限(该方法真正的目标场景,也是链方法最贵之处)、O$_S$ 幻影态检验均未做; 本页的 MODE C 是同一套数据上的直接精确折叠,跑生产链(块 Lanczos)还能额外检验链机制本身。
